# DevShowcase — Kişisel Geliştirici Portfolyosu & İnteraktif CV

Profesyonel iş deneyimlerimi, canlı yazılım projelerimi, teknik yetkinliklerimi sergilediğim ve ziyaretçilerin etkileşim kurabileceği kişisel web platformudur.

## Öne Çıkan Özellikler
- İnteraktif Özgeçmiş (CV): Akademik başarılar, çalışma deneyimleri ve teknik yeteneklerin dinamik bir akışla sunumu.
- Canlı Proje Vitrini: Geliştirilen Full-Stack, GIS, Yapay Zeka ve Blockchain projelerinin canlı yayın ve kaynak kod bağlantıları.
- İnteraktif Soru-Cevap & İletişim: Ziyaretçilerin, teknik liderlerin ve işe alım uzmanlarının doğrudan soru sorabileceği ve mesaj iletebileceği etkileşimli alan.
- Modern & Duyarlı Tasarım: Tüm ekran boyutlarında akıcı, hızlı ve optimize kullanıcı deneyimi.

## Teknolojiler
- React / Next.js
- TypeScript / JavaScript
- Tailwind CSS
- Vercel (Canlı Dağıtım)
